## Create The Repo

1. Go to GitHub.
2. Click the `+` icon in the top-right.
3. Click `New repository`.
4. Repository name: `hospital-financial-exposure-dashboard`
5. Set visibility to `Public`.
6. Add the recommended description.
7. Create the repository.
8. Upload the files from this folder.

## Pin The Repo

1. Go to your GitHub profile: `https://github.com/beatricekungu`
2. Find the pinned repositories section.
3. Click `Customize your pins`.
4. Search for `hospital-financial-exposure-dashboard`.
5. Select the repository.
6. Click `Save pins`.
